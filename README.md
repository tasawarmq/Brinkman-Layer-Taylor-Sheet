# A Taylor swimming sheet under a finite Brinkman layer

Mathematica notebooks and figure source files associated with the following publication:

Tasawar Iqbal, Catherine Penington, Christian Thomas, and Lyndon Koens, “A Taylor swimming sheet under a finite Brinkman layer,” *Physical Review Fluids* **10**, 074102 (2025). [https://doi.org/10.1103/s7jz-7k79](https://doi.org/10.1103/s7jz-7k79)

## Contribution and provenance

I developed the Mathematica notebooks during my PhD research at Macquarie University, under the supervision of Catherine Penington, Christian Thomas, and Lyndon Koens. The paper was coauthored by all four of us.

This repository is a fork of [LKoens/Brinkman-Layer-Taylor-Sheet](https://github.com/LKoens/Brinkman-Layer-Taylor-Sheet), where the files were originally made publicly available. The upstream Git history and license are retained.

## Files

- `NBN First Order Solution.nb`: first-order Mathematica calculations.
- `NBN Second Order Solution.nb`: second-order Mathematica calculations.
- `slip.nb`: Mathematica calculations involving the slip condition.
- `mean_beta.odg`, `means_base.odg`, `means_viscosity.odg`: editable figure source files.

The `.nb` files require Wolfram Mathematica. The `.odg` files can be opened with LibreOffice Draw or compatible software.
